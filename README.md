# incrmntl.co

One-page site for INCRMNTL, served by GitHub Pages.

- `index.html` — the whole site. No build step, no dependencies.
- `CNAME` — tells GitHub Pages which domain to answer on. Do not delete it;
  GitHub rewrites it from the repo settings and losing it drops the domain.
- `favicon.svg` — the node mark from the brand pack.

To change the site: edit `index.html`, commit, push. Pages redeploys in about
a minute.
